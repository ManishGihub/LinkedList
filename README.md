# 🔗 LinkedList in Java

A Java project focused on understanding and implementing **Linked List** data structures. This repository includes a custom implementation of a **Singly Linked List**, examples using Java's built-in `LinkedList` class, and solutions to popular Linked List problems from LeetCode.

---

## ✨ Overview

This repository is a collection of Linked List implementations and coding exercises to strengthen Data Structures & Algorithms (DSA) concepts.

### 📌 What You'll Find

- 🏗️ Custom Singly Linked List implementation
- ➕ Insertion and deletion operations
- 🔄 Iterative and recursive Linked List reversal
- 📚 Java Collections Framework (`LinkedList`)
- 🧠 Fast & Slow Pointer techniques
- 💻 LeetCode Linked List solutions
- 📝 Practice problems

---

# 📂 Repository Structure

### 🏗️ Core Implementations

- 📄 **SinglyLinkedList.java**  
  Custom implementation of a Singly Linked List with operations like insertion, deletion, traversal, and size calculation.

- 📄 **ReverseLL.java**  
  Reverse a Linked List using both **Iterative** and **Recursive** approaches.

- 📄 **LLWithCollections.java**  
  Demonstrates basic operations using Java's built-in `LinkedList` class.

---

### 💻 LeetCode Solutions

- ✅ **LinkedListCycle.java**  
  Detects a cycle in a Linked List using **Floyd's Cycle Detection Algorithm**.

- ✅ **PalindromeLinkedList.java**  
  Checks whether a Linked List is a palindrome using the **Fast & Slow Pointer** technique.

- ✅ **RemoveFromEnd.java**  
  Removes the **N-th node from the end** of a Linked List.

---

### 📝 Practice Problems

- 🔍 **SearchElement.java**  
  Searches for a given element in a Linked List and prints its index.

- 🗑️ **RemoveGreaterThan25.java**  
  Removes all nodes whose values are greater than **25**.
